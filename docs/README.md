# Documentação do ADCS Presença

Este diretório concentra a documentação técnica, funcional, operacional e de qualidade do produto ADCS Presença.

O Product Office permanece como a fonte oficial de documentação e governança do produto. Os documentos armazenados neste repositório representam a versão controlada junto ao código-fonte e devem permanecer alinhados ao Product Office.

## Estrutura documental

### `adr/`

Registros de Decisões Arquiteturais — Architecture Decision Records.

Armazena decisões técnicas, arquiteturais e operacionais relevantes, incluindo:

- escolha de tecnologias;
- estratégia de Git e branches;
- estratégia de ambientes;
- decisões sobre Firebase;
- padrões de segurança;
- decisões de integração;
- mudanças arquiteturais relevantes.

Padrão de nomenclatura:

```text
ADR-001-titulo-da-decisao.md
